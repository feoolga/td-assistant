# td-assistant

Тестовый ассистент для работы с технической документацией.

## Функциональность

- Чат с AI-ассистентом
- Голосовой ввод (Web API, без библиотек)
- Прикрепление изображений с превью
- Настройка "энциклопедичности" ответов

## Технологии

- React 18
- TypeScript
- TailwindCSS
- Vite

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Структура проекта:
src/
├── api/          # Работа с бэкендом
├── components/   # UI компоненты
├── hooks/        # Кастомные хуки
├── types/        # TypeScript типы
└── styles/       # CSS стили
